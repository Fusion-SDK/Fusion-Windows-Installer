# Contributing to Fusion Installer

1. Open an issue before large changes.
2. Keep changes focused and document new behavior.
3. Run `dotnet build Fusion.sln -c Release`.
4. Run `dotnet test Fusion.sln -c Release`.
5. Never commit secrets, game files, proprietary assets, or user data.
6. Do not enable mod activation without the approved package-security and loader design.

By submitting a contribution, you agree that it may be distributed under this repository's MIT License.
